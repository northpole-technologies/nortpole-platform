# Changelog

All notable changes to the Northpole Platform will be documented in this file.

The format is based on Keep a Changelog.

---

## [0.1.0] - 2026-07-22

### Added

- Northpole modular platform architecture
- Automatic module discovery
- Module manifest (`module.json`) support
- Dynamic Service Provider registration
- Northpole core namespace
- SantaBuddy demonstration module
- Independent module routing
- Independent module controllers
- Independent Blade view loading
- Module API endpoint
- Feature test suite for SantaBuddy

### Changed

- Renamed Platform namespace to Northpole
- Moved module responsibility into module Service Providers

### Verified

- Module discovery
- Route registration
- Controller loading
- View loading
- API endpoint
- Automated tests
