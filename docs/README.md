# Documentation Philosophy

NorthPole documentation follows the same principles as the platform itself.

- Architecture before implementation
- Explicit over implicit
- Deterministic by design
- Documentation evolves with the code
- Examples over theory

# Contributing

Documentation is considered part of the implementation.

If you introduce a new Runtime component, registry or architectural concept, please update the relevant documentation as part of the same pull request.
