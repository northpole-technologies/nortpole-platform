# Northpole Platform

Northpole is a Laravel-based modular application platform designed to host complete business applications as independent modules.

## Vision

Build once.

Install anywhere.

Every application is a self-contained module.

Examples include:

- SantaBuddy
- Home Doctor
- FrontGuard
- BalanceMe
- CV Station

## Current Version

v0.1.0

## Current Features

- Automatic module discovery
- Dynamic module registration
- Independent Service Providers
- Web & API routing
- Blade view loading
- Feature testing
